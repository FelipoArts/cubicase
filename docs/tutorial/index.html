Tutorial do Cubicase

Tudo sobre o programa, do primeiro clique aos recursos mais avançados. Escolha um assunto no menu ao lado ou use a busca. Os nomes de botões, abas e campos aparecem assim, do jeito que estão no app.

Básico

O que é o Cubicase

O Cubicase é um programa para Windows que cria, roda e compartilha servidores de Minecraft sem você precisar mexer no roteador.

A ideia em uma frase

Normalmente, para jogar com amigos em um servidor caseiro você precisa abrir portas no roteador, descobrir seu IP, configurar firewall e instalar Java. O Cubicase faz tudo isso sozinho: ele baixa o Java certo, instala o servidor, e conecta você e seus amigos por uma rede privada (mesh), um tipo de VPN, sem abrir nenhuma porta.

Os dois papéis

PapelAba no appO que faz
Host (anfitrião)HostCria e mantém o servidor no próprio computador. Precisa estar com o Cubicase aberto e o servidor ligado para os amigos entrarem.
ConvidadoConvidadoEntra no servidor de outra pessoa usando um código (ou link) de convite. Não precisa criar servidor nenhum.

Você pode ser as duas coisas: hospedar um servidor seu e também ter servidores de amigos na sua biblioteca.

Como as peças se encaixam

  1. O host cria um servidor (versão do Minecraft, tipo, memória) e clica em iniciar.
  2. O Cubicase conecta o servidor aos seus amigos automaticamente e gera um código de convite no formato CF-XXXX.
  3. O host manda o código (ou um link) para os amigos.
  4. O convidado cola o código na aba Convidado, clica em Preparar e Jogar e o Cubicase cuida do resto: mods, versão e conexão.
Precisa de conta?

Não. O Cubicase funciona sem login. A conta só é necessária para o Cubicase Plus ou para vincular servidores a um perfil. Veja Conta e login.

Básico

Instalar e atualizar

Do download à primeira abertura, e como o app se mantém atualizado.

Requisitos

  • Windows 10 ou 11, 64 bits.
  • Conexão com a internet (para baixar o servidor, o Java e conectar com seus amigos).
  • RAM suficiente para o servidor: o mínimo aceito pelo app é 2 GB para o servidor, mas recomenda-se 3 GB ou mais, sempre deixando pelo menos 2 GB livres para o Windows.
  • Para jogar, você também precisa do Minecraft Java Edition instalado.

Instalando

  1. Acesse a página de download e clique em Baixar para Windows.
  2. Abra o instalador .exe baixado. Não é preciso configurar nada durante a instalação.
  3. Ao terminar, abra o Cubicase.
Aviso do Windows SmartScreen

Como o Cubicase é um projeto novo, o Windows pode mostrar "O Windows protegeu seu PC". É normal: clique em Mais informações e depois em Executar assim mesmo. O código-fonte é aberto no GitHub se você quiser conferir.

Primeira abertura

Na primeira vez, o app mostra uma tela de boas-vindas perguntando o que você quer fazer: Hospedar um servidor (criar e gerenciar seu servidor) ou Conectar a um servidor (entrar no servidor de um amigo com um código). Isso só define qual aba abre primeiro, e você muda depois em Configurações → Início.

Atualizações

O Cubicase verifica novas versões sozinho. Quando há uma, aparece um aviso "Nova versão disponível" com o botão Atualizar e reiniciar. O app baixa a atualização, mostra o progresso e reinicia. Se falhar, ele avisa e você pode tentar mais tarde. O número da versão instalada aparece no rodapé de Configurações.

O aviso pode ser dispensado, mas o botão Atualizar continua na barra superior enquanto houver uma versão nova. Se a instalação falhar, ele muda para Tentar de novo: o app confere de novo se há atualização e tenta instalar, sem precisar fechar e abrir o programa. Depois de uma falha, ele fica desativado por alguns segundos para não sobrecarregar o servidor, e cliques repetidos são ignorados.

Atualizar com o servidor ligado

Reiniciar o app para atualizar interrompe o que estiver rodando. Faça isso quando não houver ninguém jogando.

Conhecendo a interface

Um mapa rápido de tudo o que aparece na janela do Cubicase.

Barra superior e atalhos gerais

  • Abas Host e Convidado: alternam entre gerenciar o seu servidor e usar a biblioteca de servidores de amigos.
  • Configurações: preferências do app: aba inicial, backups, tema, idioma, conta e assinatura. Veja Configurações do app.
  • Alternador de tema: muda entre modo claro e escuro rapidamente (também em Configurações).
  • Botão Atualizar: só aparece quando há uma versão nova. Se a atualização automática falhar, ele vira Tentar de novo e você tenta outra vez sem fechar o app.
  • Botão ? (Central de ajuda): abre atalhos para este tutorial e o formulário para reportar bugs, problemas ou sugestões. Veja Central de ajuda e contato.
  • Central de diagnósticos: o histórico de avisos e erros (rede, servidor, instalação…). Veja Diagnósticos.

Aba Host

  • Lista Servidores Locais (barra lateral): todos os servidores que você criou ou importou. Aqui ficam os botões para criar, importar servidor e importar modpack.
  • Painel do servidor selecionado: nome, status (Online, Iniciando, Parando, Crash, Offline), código de convite, botões de iniciar/parar e uso de RAM/CPU.
  • Convide seus amigos: o código para compartilhar e o estado da conexão (os detalhes técnicos ficam recolhidos).
  • Console: duas abas, Minecraft Console e Conexão, com os logs ao vivo.
  • Gerenciamento: jogadores, mods/plugins, mundo e backups.

Aba Convidado

A Biblioteca de Servidores Conhecidos: cada servidor em que você já entrou fica salvo, com status, jogadores e o botão de jogar.

Ao fechar a janela

O Cubicase pergunta o que fazer: Manter em segundo plano (servidor e rede continuam rodando) ou Fechar tudo (encerra servidor, rede e app). Veja Segundo plano.

Básico

Criar um servidor

Do clique no "+" até o servidor instalado, passo a passo.

  1. Na aba Host, na lista Servidores Locais, clique no botão + e escolha Criar Novo Servidor.
  2. Preencha o Nome do Servidor (ex.: Meu_Servidor). Veja as regras de nome abaixo.
  3. Escolha o Tipo do Servidor. Se estiver em dúvida, veja Qual tipo escolher.
  4. Escolha a Versão do Minecraft. O seletor tem busca e agrupa as versões em Recomendadas, Populares e Todas as Versões.
  5. Se o tipo for Forge, Fabric ou Paper, aparece mais um seletor (versão do Forge, do Fabric Loader ou build do Paper). O app já marca a opção recomendada/estável.
  6. Ajuste a RAM Alocada (veja abaixo).
  7. Opcionalmente, informe uma Semente do Mundo.
  8. Clique em Criar Servidor e aguarde a instalação.

Regras para o nome

  • Não pode ficar vazio nem repetir o nome de outro servidor seu.
  • Não pode conter os caracteres \ / : * ? " < > |.
  • Não pode terminar com espaço ou ponto.
  • Não pode ser um nome reservado do Windows (como CON, NUL, COM1).

Versão do Minecraft

O Cubicase oferece versões a partir da 1.8.9. Na dúvida, fique nas Recomendadas. Se seus amigos usam uma versão específica (ou o modpack exige uma), escolha exatamente ela: todos precisam jogar na mesma versão do servidor.

RAM alocada

É a memória que o servidor pode usar. O app mostra o total do seu PC e avisa:

  • Menos de 3 GB: pode causar lentidão ou travamentos, principalmente com muitos jogadores ou mods.
  • Sobrar menos de 2 GB para o Windows: pode deixar o sistema lento ou instável, então reduza.

Regra prática: servidor vanilla com poucos amigos roda bem com 3-4 GB; modpacks pesados pedem 6-8 GB ou mais, se o PC permitir. Você pode alterar depois em Configurações do Servidor.

Semente do mundo

Deixe em branco para um mundo aleatório. Se quiser um mundo específico, digite a semente (seed). Só dá para definir agora: o mundo é gerado na primeira vez que o servidor liga e a semente não pode mais ser trocada. Para gerar outro mundo depois, use Resetar Mundo (veja Mundo e backups).

O que acontece na instalação

  • Os arquivos oficiais do servidor são baixados (Mojang, Forge, Fabric ou Paper conforme o tipo). Isso acontece uma vez por versão instalada.
  • O Java necessário é baixado automaticamente quando faltar (veja Java automático).
  • O Cubicase aceita o EULA do Minecraft e cria o server.properties inicial por você.
Ao aceitar o EULA

Ao criar o servidor pelo Cubicase, o EULA do Minecraft é aceito automaticamente em seu nome. Vale ler os termos em minecraft.net/eula.

Básico Intermediário

Qual tipo de servidor escolher

Vanilla, Forge, NeoForge, Fabric ou Paper: o que cada um faz e quando usar.

TipoO que éExtensõesUse quando…
VanillaO servidor oficial da Mojang, sem alterações.NenhumaQuer o Minecraft puro, é a primeira vez, ou o grupo joga sem mods.
ForgeCarregador de mods clássico, com o maior catálogo de mods e modpacks.ModsVai jogar um modpack ou mods que exigem Forge.
NeoForgeSucessor do Forge nas versões mais novas. O Cubicase o oferece junto com o Forge, na lista de versões do Forge.ModsO mod ou modpack pede NeoForge.
FabricCarregador de mods leve e rápido, muito usado em mods de desempenho.ModsOs mods que você quer são para Fabric.
PaperServidor otimizado para desempenho, que aceita plugins.PluginsQuer melhor desempenho com muita gente e plugins de administração (o jogador entra com o Minecraft normal, sem mods).

Mods versus plugins

  • Mods (Forge, NeoForge, Fabric) mudam o jogo por dentro. Em geral os jogadores também precisam instalar os mesmos mods. O Cubicase faz isso pelo convidado, veja Preparar e jogar.
  • Plugins (Paper) rodam só no servidor, e o jogador entra com o Minecraft puro.
  • Mods e plugins não são intercambiáveis. Cada carregador exige os arquivos feitos para ele e para a versão do Minecraft escolhida.
Não sabe qual escolher?

Comece com Vanilla. Se quiser adicionar mods depois, crie outro servidor do tipo certo (ou importe o modpack, que já define tudo). O tipo não pode ser trocado em um servidor já criado.

Básico

Iniciar e parar o servidor

Como ligar o servidor e a rede, o que significa cada status, e como desligar com segurança.

Ligando

  1. Selecione o servidor na lista Servidores Locais. Só um servidor pode rodar por vez: pare o atual antes de trocar.
  2. Clique em Iniciar Servidor. O botão mostra Iniciando… enquanto o Minecraft sobe, e o Cubicase já conecta seus amigos automaticamente — não há mais nada para ligar.
  3. Quando tudo estiver pronto, o status muda para Online para amigos e o código de convite fica ativo para compartilhar. Quem entrou como convidado em outro servidor precisa sair de lá antes: o Cubicase pergunta e desconecta por você.
Servidor online só neste computador

Se a conexão com os amigos falhar ou cair, o servidor continua rodando e o app mostra Online só neste PC, com um aviso e o botão Tentar de novo. O Cubicase também tenta reconectar sozinho, algumas vezes. Nesse estado só quem está neste computador consegue entrar. Você também pode iniciar assim de propósito com Só neste computador (útil para testar mods) e depois clicar em Abrir para amigos.

Na primeira vez

O primeiro início pode demorar: o app baixa o Java (se faltar), e o Minecraft gera o mundo. A barra de progresso mostra o andamento e o console mostra tudo o que acontece.

Os status

StatusSignificado
OfflineServidor desligado.
IniciandoO Java subiu e o Minecraft está carregando (o app detecta o "online" testando a porta do servidor).
OnlinePronto para receber jogadores.
ParandoO servidor está salvando o mundo e encerrando.
CrashO servidor fechou de forma inesperada. Veja Erros comuns.

Desligando

  • Clique em Parar Servidor e espere chegar a Offline. O Cubicase envia o comando de parada para o Minecraft salvar tudo direito.
  • Parar o servidor também encerra a conexão com os amigos, nesta ordem: primeiro o Minecraft salva o mundo, depois a conexão é desligada.
  • Pelo console você também pode usar stop.
Evite matar o processo

Fechar o Java à força, desligar o PC da tomada ou encerrar pelo Gerenciador de Tarefas pode corromper o mundo. Sempre pare pelo botão. Se acontecer, restaure um backup.

Java automático

Você não precisa instalar Java. O Cubicase escolhe e baixa (do Adoptium) a versão que a sua versão do Minecraft exige e guarda na pasta de dados do app:

MinecraftJava usado
1.16 e anterioresJava 8
1.17 a 1.20.4Java 17
1.20.5 em dianteJava 21

Se o Java de um servidor estiver corrompido ou incompatível, o Cubicase detecta, reinstala sozinho e tenta iniciar de novo, avisando com "Corrigindo automaticamente".

Básico

Convidar amigos (código e link)

Três formas de passar seu servidor para os outros: código, link e endereço.

Código do servidor

Todo servidor tem um código no formato CF-XXXX. Para copiar, use Copiar Código do Servidor (ou Copiar Código) no painel do servidor. O convidado só precisa dele uma vez, porque depois o servidor fica salvo na biblioteca dele.

Link de convite

O botão Copiar link de convite copia um endereço no formato play.cubicase.net/…. Ao abrir o link, o Cubicase do convidado abre e adiciona o servidor na biblioteca. Isso funciona através do protocolo cubicase://join/…, então o convidado precisa ter o Cubicase instalado.

O link gratuito é baseado no código. Com o Cubicase Plus é possível escolher um endereço personalizado (ex.: play.cubicase.net/meu-servidor) em Configurações do Servidor.

Endereço no Minecraft

Em Configurações do Servidor → Endereço no Minecraft fica o endereço que o jogador usa na lista de Multiplayer. O endereço gratuito é baseado no código e só funciona enquanto o convidado está conectado pelo app. Com o Plus você pode escolher um nome próprio.

Gerar um novo código

Ao lado do código há a opção de Gerar novo código. Use quando o código vazou ou alguém que você não quer mais ali o tem.

  • O código antigo deixa de funcionar imediatamente: quem só tinha ele não entra mais.
  • Você precisa passar o novo código a quem já joga com você.
  • Só é possível gerar um novo código com o servidor parado.
Quer controlar quem entra de verdade?

O código dá acesso a qualquer pessoa que o tenha. Ative a whitelist para que só nomes aprovados consigam jogar.

Intermediário

Console do servidor

Acompanhe o que o Minecraft e a rede estão fazendo e envie comandos.

As duas abas

  • Minecraft Console: toda a saída do servidor (jogadores entrando, avisos, erros). Só mostra algo depois que você inicia o servidor.
  • Conexão: logs da conexão com os amigos. Útil para diagnosticar quando ninguém consegue conectar.

O botão Limpar apaga o que está na tela (não apaga arquivos de log do servidor).

Enviando comandos

A caixa de texto no rodapé do console só aceita comandos quando o servidor está Online. Digite sem a barra e aperte Enter. Alguns comandos úteis:

Vários desses comandos exigem que a versão e o tipo do servidor os suportem. Servidores com plugins (Paper) e mods podem ter comandos extras.

Intermediário

Jogadores: whitelist, operadores e bans

O painel Jogadores controla quem pode entrar e quem manda no servidor, sem digitar comandos.

Com o servidor online, as ações desse painel são enviadas como comando pelo console e têm efeito imediato. O painel tem quatro abas:

Online

Mostra quem está conectado agora. Com o servidor desligado, aparece "Servidor offline — nenhum jogador conectado".

Whitelist (lista de aprovados)

Enquanto a whitelist está desativada, qualquer pessoa com o código consegue entrar. Um aviso no painel lembra disso, com o botão Ativar whitelist.

  1. Clique em Ativar whitelist.
  2. Na aba Whitelist, digite o Nome do jogador (exatamente o nick do Minecraft) e clique em Adicionar.
  3. Para tirar alguém, use Remover da whitelist e confirme.

Você também pode ligar/desligar a whitelist em Configurações do Servidor → Lista de Aprovados.

Operadores

Operadores (ops) têm permissão de administrador dentro do jogo: podem usar comandos como gamemode e ban. Adicione com Tornar Operador; a lista mostra o UUID e o nível de cada um. Remova com Remover operador.

Cuidado com quem vira operador

Um operador pode banir, mudar o modo de jogo e, dependendo do nível, até desligar o servidor. Dê esse poder só a quem você confia.

Banidos

  • Banir: digite o nome e, se quiser, um Motivo (opcional).
  • Banir IP: bloqueia um endereço IP inteiro.
  • A lista tem duas seções, Jogadores banidos e IPs banidos. Use Desbanir ou Remover banimento para reverter.

O botão Atualizar listas recarrega tudo caso algo tenha mudado por comando no console.

Intermediário

Mods e plugins

Instale, desative e remova mods (Forge, NeoForge, Fabric) ou plugins (Paper) sem sair do app.

Em servidores com mod loader o painel se chama Mods e usa a pasta mods. Em servidores Paper ele se chama Plugins e usa a pasta plugins. Servidores Vanilla não usam nenhum dos dois.

Buscar e instalar online

Ao criar um servidor com mods ou plugins, essa janela abre sozinha: é a hora ideal para instalar mods de geração de mundo ou de terreno, que precisam estar no servidor antes da primeira partida. Você pode fechar e voltar depois.

  1. Clique em Buscar Mods Online (ou Buscar Plugins Online). A busca reúne o Modrinth e o CurseForge numa lista só: cada item mostra em qual dos dois ele está.
  2. A janela já abre com os mais populares. Use Categoria e Ordem para explorar, ou digite um nome (ex.: Sodium, WorldEdit). Só aparece o que é compatível com este servidor.
  3. Para instalar direto, clique em Instalar na própria linha: o app escolhe a versão mais recente compatível e instala também as dependências obrigatórias. A janela continua aberta, então dá para instalar vários em sequência.
  4. Para escolher a versão ou ver as dependências antes, abra o item. Em Dependências não detectadas há caixas para instalá-las juntas; se você já instalou manualmente, é só desmarcar.
  5. Reinicie o servidor: mudanças em mods e plugins só valem depois disso.
Se a busca não aparece

A busca precisa que o app detecte a versão do Minecraft do servidor (em servidores importados isso pode falhar). Se uma das fontes estiver inacessível, a busca segue com a outra e avisa; só se as duas falharem você vê "Sem conexão" e um botão para tentar de novo. Os mods já instalados continuam gerenciáveis.

Mods que o autor não libera para download

Alguns autores bloqueiam o download por aplicativos de terceiros no CurseForge. O Cubicase tenta pegar o mesmo arquivo no Modrinth (confere pelo hash, então é idêntico). Se também não existir lá, o botão de instalar fica desabilitado e a página do mod abre para você baixar à mão.

Modpacks prontos

Na aba Modpacks da mesma janela você instala um modpack inteiro no servidor que já existe. A lista mostra só os compatíveis com a versão do Minecraft e o loader do servidor. Antes de mexer em qualquer coisa, o app baixa tudo e mostra um resumo: quantos mods são novos, quantos já estão presentes e quantos existem em outra versão.

  • Manter as versões do servidor (recomendado): o que já funciona não é alterado.
  • Usar as versões do pacote: os arquivos antigos vão para a pasta mods-backup, sem serem apagados.

Mods repetidos entre dois modpacks não são duplicados, mesmo que o nome do arquivo seja diferente: o app identifica cada mod pelo id que ele declara por dentro. Os arquivos de configuração do pacote nunca sobrescrevem os seus. Juntar modpacks não garante que funcionem juntos.

Gerenciar o que já está instalado

  • Buscar: o campo acima da lista filtra enquanto você digita, pelo nome do arquivo ou pelo id do mod. Selecionar todos e excluir em lote valem só para o que a busca está mostrando.
  • Duplicado: um selo avisa quando o mesmo mod aparece em dois arquivos ativos (versões diferentes, por exemplo), o que pode impedir o servidor de iniciar. Remova um dos dois.
  • Desabilitar / Habilitar: desliga um mod sem apagá-lo (bom para testar qual mod dá problema).
  • Excluir: remove o arquivo, com confirmação. Dá para selecionar vários (Selecionar todos) e usar Excluir selecionados.
  • Abrir Pasta de Mods: abre a pasta no Explorer, para copiar arquivos .jar baixados de outros sites.
  • Atualizar lista: relê a pasta.

Mods pendentes

Se um modpack tem mods que não puderam ser baixados em nenhuma fonte, o painel mostra um aviso "N mods precisam ser baixados manualmente", com o nome de cada um, o modpack de origem e o botão Abrir página. Baixe o arquivo e coloque na pasta de mods: quando o app o encontra, o mod sai da lista sozinho. Ao iniciar o servidor com pendências, o app pergunta se você quer continuar assim.

Instalação manual

Copie o arquivo .jar para a pasta do painel e clique em Atualizar lista. Confira que o mod é da mesma versão do Minecraft e do mesmo loader do servidor.

Dica de diagnóstico

Servidor travando depois de instalar algo? Desabilite os últimos mods adicionados, um de cada vez, e reinicie. Veja também Erros comuns.

Intermediário

Mundo e backups

Proteja o progresso do seu mundo: backups manuais, automáticos, restaurar e recomeçar do zero.

Backup manual

  1. Pare o servidor. O app só gerencia backups com ele desligado, para não copiar o mundo no meio de uma escrita.
  2. Na aba Mundo, clique em Fazer Backup Agora.
  3. O backup aparece na lista Backups.

Backups automáticos

Configurados em Configurações → Backups (veja Configurações do app). Quando ligados, o Cubicase gera um backup sozinho:

  • quando o servidor é parado;
  • quando o servidor crasha;
  • periodicamente em sessões longas (intervalo em horas, configurável).

Ele pula sozinho se o mundo não mudou desde o último. Você define quantos backups manter (Manter últimos N backups): os mais antigos, automáticos ou manuais, são apagados.

Restaurar um backup

  1. Pare o servidor.
  2. Na lista de backups, clique em Restaurar backup no desejado.
  3. Confirme digitando RESTAURAR.
Restaurar substitui o mundo atual

O progresso atual do mundo é perdido. Se tiver dúvida, faça um backup do estado atual antes.

Resetar o mundo

Resetar Mundo apaga o mundo atual permanentemente; o Minecraft gera um novo na próxima vez que o servidor iniciar. A confirmação exige digitar RESETAR. Faça um backup antes se houver qualquer chance de você querer o mundo antigo de volta.

Onde ficam os backups

Ficam numa pasta CubicaseBackups, separados por nome de servidor. Se você renomear o servidor, o Cubicase move os backups junto; se não conseguir, avisa onde eles ficaram para você mover manualmente.

Boa prática

Backups na mesma máquina não protegem contra falha do disco. De vez em quando copie a pasta CubicaseBackups para um pen drive ou nuvem.

Intermediário

Configurações do Servidor

Um formulário para todas as opções do server.properties e mais, sem editar arquivo nenhum.

Abra com o botão Configurações do Servidor no painel do servidor. Duas regras importantes:

  • As opções só podem ser alteradas com o servidor parado. Com ele rodando, o app avisa "Servidor em execução".
  • Se o app não conseguir ler as configurações reais, ele bloqueia o formulário em vez de arriscar sobrescrever tudo com valores errados. Feche e tente de novo.

Intermediário

Importar um servidor existente

Já tem um servidor de Minecraft numa pasta? Traga ele para o Cubicase sem copiar nem perder nada.

  1. Na lista Servidores Locais, clique em + e escolha Importar Servidor Existente.
  2. Selecione a pasta onde está o servidor (a que contém o server.jar ou equivalente).
  3. O Cubicase analisa a pasta e detecta o tipo e a versão. Depois, o servidor aparece na lista e o log confirma a importação.

O que muda para servidores importados

  • Os arquivos continuam na pasta original. O Cubicase só passa a gerenciá-los ali.
  • Não é possível renomear o servidor pelo Cubicase, pois o nome vem da pasta.
  • Se a versão do Minecraft não for detectada, a busca online de mods fica indisponível e a versão aparece como "Não encontrada".
  • Um servidor que já esteja na lista não pode ser importado de novo ("Servidor já importado").

Removendo da lista

Ao excluir um servidor importado, o Cubicase apenas o remove da lista. Os arquivos originais na pasta não são apagados. Já em servidores criados pelo Cubicase, a exclusão apaga tudo (veja Excluir um servidor).

Avançado

Importar um modpack

Crie um servidor moddado a partir de um arquivo de modpack, com loader, versão e mods configurados automaticamente.

O Cubicase aceita dois formatos: .zip (CurseForge) e .mrpack (Modrinth).

  1. Baixe o arquivo do modpack no site do CurseForge ou do Modrinth.
  2. Na lista Servidores Locais, clique em + e escolha Importar Modpack (.zip/.mrpack).
  3. Clique em Clique para selecionar o arquivo e escolha o modpack.
  4. O app lê o pacote e mostra um resumo: versão do Minecraft, loader e quantidade de mods.
  5. Informe o Nome do Servidor e a RAM Alocada (modpacks grandes pedem bastante) e clique em Importar Modpack.
  6. Aguarde: o Cubicase instala o mod loader e baixa todos os mods. A barra mostra o percentual e modpacks grandes podem levar alguns minutos.
Mods que precisam de download manual

Alguns autores desativam a distribuição por terceiros. O app primeiro tenta achar o mesmo arquivo no Modrinth; o que não existir lá fica numa lista de mods pendentes do servidor, com um botão para abrir a página de cada um. Baixe-os e coloque na pasta mods (use Abrir Pasta de Mods): eles saem da lista sozinhos.

Já tem um servidor e quer somar um modpack a ele? Use a aba Modpacks de Mods e plugins.

Depois de importado, seus amigos entram normalmente. O Preparar e Jogar deles instala os mesmos mods na máquina de cada um (veja Preparar e jogar).

Excluir um servidor

Como apagar um servidor e o que exatamente é perdido.

  1. Pare o servidor. Não é possível excluir um servidor em execução.
  2. Na lista Servidores Locais, use Deletar Servidor no servidor desejado.
  3. Para confirmar, digite o nome do servidor e clique em Excluir Permanentemente.

Para servidores importados, só a entrada na lista é removida.

Conexão manual e túnel

Como a conexão funciona por baixo, e como conectar do jeito "clássico" pela lista de Multiplayer.

Conectar / Desconectar

Ao clicar em Conectar no cartão do servidor, o Cubicase estabelece um túnel pela rede privada até o host. Quando termina, o cartão mostra Conectado e a mensagem "Conecte-se em <endereço> no seu Minecraft".

  • O app tenta adicionar o servidor automaticamente à sua lista de Multiplayer do Minecraft.
  • Se não achar sua instalação ou não conseguir, copie o endereço com Copiar endereço e adicione você mesmo: no Minecraft, Multiplayer → Adicionar servidor, e cole o endereço.

Um túnel por vez

Uma instalação do Cubicase usa a rede privada ou como host ou como convidado por vez. Se você está conectado como convidado, o botão de rede do host fica bloqueado ("Em uso pelo modo Convidado"), e o inverso também. Pare uma antes de usar a outra.

Porta local de convidado

Em Ajustes do Sistema existe a Porta Local de Convidado (padrão 25565): a porta local usada apenas quando você entra no servidor de outra pessoa. Ela não afeta os servidores que você hospeda, cuja porta é definida em Configurações do Servidor. Só mude se outro programa já estiver usando a 25565.

Cubicase Plus

O Cubicase é grátis. O Plus é uma assinatura opcional que libera recursos extras.

O que o Plus libera

  • Servidor sob demanda: o servidor liga sozinho quando alguém tenta entrar e desliga sozinho depois de um tempo sem jogadores.
  • Link de convite personalizado: play.cubicase.net/seu-nome.
  • Endereço personalizado no Minecraft: um nome fácil de lembrar em vez do baseado no código.

Assinar

  1. Entre na sua conta (veja Conta e login).
  2. Em Configurações → Assinatura, escolha o plano Mensal ou Anual.
  3. Conclua o pagamento na página segura que abrir no navegador.

Depois de assinar, o plano ativo aparece com a data de renovação (ou cancelamento). Gerenciar assinatura abre o portal para trocar de plano, atualizar o pagamento ou cancelar.

Configurando o servidor sob demanda

  1. Selecione um servidor na aba Host (é preciso ter um servidor selecionado).
  2. Em Configurações → Assinatura → Servidor sob demanda, ative a opção.
  3. Defina Desligar sem jogadores após quantos minutos.
Inicie o servidor pelo menos uma vez antes

O modo de espera precisa que o Java do servidor já esteja instalado. Se aparecer "Java ainda não instalado para este servidor", inicie o servidor manualmente uma vez.

Com o modo ativo, o painel do servidor mostra o aviso “Desligando por inatividade em N s” pouco antes de desligar, com o botão Manter ligado para cancelar.

Parei o servidor e ele não acorda mais

Isso é de propósito. Quando você clica em Parar Servidor com o modo sob demanda ligado, a espera fica pausada: o cartão mostra Espera pausada e um aviso, e seus amigos não conseguem acordar o servidor (assim ninguém o liga no meio de uma troca de mods ou de um backup). Para reativar, clique em Voltar à espera no aviso, ou em Iniciar Servidor. Já o desligamento por inatividade, ou um stop digitado no console, não pausam: o servidor volta sozinho à espera. Se você fechar e abrir o Cubicase, a espera também volta ao normal.

Intermediário Avançado

Diagnósticos e alertas automáticos

O Cubicase observa o servidor e o seu PC e avisa antes que o problema estrague a sessão.

Central de Diagnósticos

Todo aviso importante entra no histórico da Central de Diagnósticos, classificado por origem (Rede, Servidor, Painel, Convite, Instalação, Backup) e nível (Info, Aviso, Erro, Crítico). Use Dispensar para fechar um aviso e Limpar histórico para esvaziar a lista.

Detecção de lag

AlertaO que quer dizer
Servidor com lagO servidor teve dificuldade de acompanhar o ritmo do jogo várias vezes no último minuto. Costuma ser mods pesados, geração de terreno excessiva ou pouca RAM/CPU.
Lag severoO servidor está muitos milissegundos atrasado e pode travar em breve.
Servidor travando (Watchdog)O próprio Minecraft detectou uma trava grave: algum mod ou plugin pode estar em loop. Se repetir, o servidor pode cair.

Análise de recursos

Quando há lag, o app olha se o gargalo é o processador ou a memória do PC, e diz qual:

  • CPU no limite: reduza a Distância de Visão, remova mods pesados ou (a longo prazo) melhore o processador.
  • RAM quase toda ocupada: reduza a RAM alocada ao servidor, feche outros programas ou aumente a RAM do PC.
  • Nenhum dos dois no limite: a causa provável é um mod/plugin específico ou muitas entidades/jogadores carregados.

Também há avisos de pressão sustentada: CPU ou RAM do computador acima do normal por alguns minutos, antes mesmo de aparecer lag. Uma barra de uso de RAM/CPU do computador (não só do servidor) fica sempre visível no painel.

Sem memória (OutOfMemory)

Se o servidor ficar sem RAM, o app compara o que você alocou com o total do PC:

  • Se o PC tem folga, sugere um valor seguro para aumentar em Configurações do Servidor.
  • Se o PC já está no limite, sugere reduzir mods/jogadores, diminuir um pouco a RAM alocada ou fazer upgrade de RAM.
Intermediário Avançado

Erros comuns e crashes

Quando o servidor fecha sozinho, o Cubicase lê o log e explica o motivo mais provável, em português.

Um aviso vermelho aparece no painel com o título e a explicação. Clique em Ver detalhes técnicos para o trecho bruto do log (útil para pedir ajuda). Se o Backup automático estiver ligado, um backup também é feito no crash. Causas que o app reconhece:

DiagnósticoCausa e solução
Dois mods com o mesmo IDUm mod está duplicado (baixado duas vezes, ou embutido em outro). Apague a cópia extra da pasta mods.
Falta um mod ou bibliotecaUm mod exige outro (dependência) que não está instalado ou está em versão incompatível. Instale o que falta. A busca online de mods sugere dependências.
Conflito entre mods (mixin)Dois mods alteram a mesma parte do jogo. Descubra o último mod adicionado, desative um dos dois e teste.
Mod incompatível com a versãoAlgum mod foi feito para outra versão do Minecraft ou do Forge. Confira se todos são da mesma versão do servidor.
Mundo corrompidoUm arquivo de região/chunk está danificado (queda de energia, encerramento forçado). Restaure um backup.
Sem memória (OutOfMemoryError)Aumente a RAM alocada (se o PC tiver folga) ou reduza mods/jogadores. Veja Diagnósticos.
Servidor travou (Watchdog)Mod ou plugin preso em loop, consulta pesada demais ou disco/rede lentos. Veja nos detalhes qual mod aparece perto do erro.

Método geral para achar o culpado

  1. Leia o aviso do Cubicase e os detalhes técnicos.
  2. Lembre o que mudou: instalou um mod? mudou uma configuração? aumentou a distância de visão?
  3. Desfaça a última mudança (desabilite o mod, restaure a configuração).
  4. Se o mundo pode estar danificado, restaure um backup.
  5. Se nada resolver, procure ajuda com o log em mãos, em Issues no GitHub.

Ninguém consegue entrar

Um checklist na ordem em que os problemas mais aparecem.

Do lado do host

  1. O servidor está Online? (Se estiver em Iniciando, espere.)
  2. O status é Online para amigos? Se aparecer Online só neste PC com um aviso, clique em Tentar de novo (ou Abrir para amigos).
  3. O Cubicase está aberto e o PC não está dormindo?
  4. Você não gerou um código novo recentemente? Se sim, passe o novo código.
  5. Está usando o app como convidado de outro servidor no momento? Isso ocupa a rede (veja Conexão manual e túnel).
  6. Olhe a aba Conexão do console por erros.

Do lado do convidado

  1. O código está correto? "Servidor não encontrado" indica erro no código ou código antigo.
  2. O status no cartão está Online? Se for Rodando só no PC do host ou Offline, o problema é do host.
  3. Usou Preparar e Jogar (ou Conectar) e esperou "Conectado"?
  4. Sua versão/mods bate com a do servidor? Rode Preparar e Jogar de novo para reinstalar o que falta.
  5. O servidor usa whitelist? Peça ao host para adicionar seu nick exato.
  6. Conta oficial do Minecraft: com Modo Online ligado (padrão), só entra quem tem conta oficial.
  7. Tente Desconectar e Conectar de novo.
Mesma versão!

Mensagens como "versão incompatível" no Minecraft significam que jogador e servidor estão em versões diferentes. No modo Convidado o botão Preparar e Jogar já abre o perfil correto.

Básico

Perguntas frequentes

É grátis?

Sim. O Cubicase é gratuito e de código aberto. O Cubicase Plus é uma assinatura opcional com recursos extras.

Preciso abrir portas no roteador?

Não. A conexão passa por uma rede privada (mesh), sem expor seu roteador.

Meus amigos precisam instalar o Cubicase?

Para entrar pelo código/link, sim: o Cubicase deles faz a conexão (e instala os mods, se houver). Só o host cria o servidor.

O servidor funciona com meu PC desligado?

Não. O servidor roda no seu computador. Se o PC ou o Cubicase estiverem desligados, ninguém entra. O modo sob demanda do Plus liga o servidor quando alguém chega, mas o computador precisa estar ligado.

Quantos jogadores aguenta?

Depende da sua RAM, CPU e internet, e do tipo de servidor. Comece com poucos amigos e observe o uso de RAM/CPU no painel. Se houver lag, veja Diagnósticos.

Posso ter vários servidores?

Sim, vários na lista, mas só um roda por vez.

Posso jogar em Bedrock, no celular ou no console?

O Cubicase é feito para o Minecraft Java Edition em Windows.

Mudei de PC. Como levo o servidor?

Copie a pasta do servidor (ou o backup) para o novo computador e use Importar Servidor Existente.

Onde ficam os arquivos do servidor?

Em Parâmetros locais → Diretório do Servidor aparece o caminho, com o botão Escolher diretório.

Como mudo o idioma do app?

Em Configurações → Idioma.

Achei um bug ou tenho uma sugestão

Use o botão ? do app (veja Central de ajuda e contato). Também dá para abrir uma issue no GitHub do projeto, se possível com o texto dos detalhes técnicos do erro.

Glossário

Termos que aparecem no app e neste tutorial.

TermoSignificado
HostQuem hospeda o servidor no próprio PC.
ConvidadoQuem entra no servidor de outra pessoa.
Rede meshRede privada virtual que liga host e convidados diretamente, sem abrir portas no roteador.
TúnelA conexão criada pela rede mesh entre você e o host.
Código (CF-XXXX)Identificador curto do servidor, usado para convidar.
VanillaMinecraft puro, sem mods nem plugins.
ModModificação do jogo. Precisa de um mod loader (Forge, NeoForge ou Fabric).
Mod loaderPrograma que carrega os mods (Forge, NeoForge, Fabric).
PluginExtensão que roda só no servidor (Paper). O jogador entra com o jogo puro.
ModpackPacote pronto de mods com configurações (CurseForge .zip, Modrinth .mrpack).
ModrinthCatálogo aberto de mods e plugins usado na busca do app.
JRE / JavaAmbiente que roda o servidor. O Cubicase baixa o certo automaticamente.
RAM alocadaMemória que o servidor pode usar.
WhitelistLista de jogadores aprovados; só eles entram.
Operador (op)Jogador com poderes de administrador.
Semente (seed)Número que define como o mundo é gerado. Só é escolhida na criação.
MOTD"Mensagem do dia": texto exibido na lista de servidores.
Distância de visãoQuantos chunks são carregados em volta de cada jogador.
ChunkBloco de 16×16 do mundo, a unidade que o servidor carrega.
WatchdogVigia interno do Minecraft que derruba o servidor quando ele trava.
Modo OnlineVerificação de conta oficial dos jogadores.
Modo sob demandaRecurso do Plus: liga o servidor quando alguém chega e desliga sem jogadores.
LANRede local (a mesma casa/roteador).
