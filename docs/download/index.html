O Windows pode mostrar um aviso — é normal

Como o Cubicase é um projeto novo e pequeno, o Windows Defender SmartScreen às vezes exibe "O Windows protegeu seu PC" no primeiro clique. Basta clicar em "Mais informações" e depois em "Executar assim mesmo". O código-fonte está disponível no GitHub, se quiser conferir.

Três passos até o primeiro mundo

Execute o instalador

2

Chame a galera

Copie o código do servidor e mande pros seus amigos entrarem pelo Cubicase deles.
