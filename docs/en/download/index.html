Windows may show a warning — that's normal

Since Cubicase is a new, small project, Windows Defender SmartScreen sometimes shows "Windows protected your PC" on the first click. Just click "More info" and then "Run anyway". The source code is available on GitHub, if you want to check it.

1

Run the installer

Illustration of the screens. The exact wording may vary a little depending on your Windows version.

Why does this appear? Cubicase doesn't have a digital publisher signature yet (it's a paid certificate, and the project is new and independent), so Windows calls the publisher "unknown". It doesn't mean there is anything wrong with the file: the code is public on GitHub and the installers are built from it by an automated process.
