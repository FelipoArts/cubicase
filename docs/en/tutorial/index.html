Cubicase Tutorial

Everything about the program, from the first click to the most advanced features. Pick a topic in the menu or use the search. The names of buttons, tabs and fields appear like this, exactly as they are in the app.

Basic

What is Cubicase

Cubicase is a Windows program that creates, runs and shares Minecraft servers without you having to touch your router.

The idea in one sentence

Normally, to play with friends on a home server you need to open ports on your router, find out your IP, configure the firewall and install Java. Cubicase does all of that for you: it downloads the right Java, installs the server, and connects you and your friends through a private (mesh) network, a kind of VPN, without opening any port.

The two roles

RoleTab in the appWhat it does
HostHostCreates and runs the server on your own computer. Cubicase must be open and the server on for friends to join.
GuestGuestJoins someone else's server using an invite code (or link). You don't need to create any server.

You can be both: host a server of your own and also keep your friends' servers in your library.

How the pieces fit together

  1. The host creates a server (Minecraft version, type, memory) and starts it.
  2. Cubicase turns on the mesh network and generates an invite code in the format CF-XXXX.
  3. The host sends the code (or a link) to friends.
  4. The guest pastes the code in the Guest tab, clicks Prepare and Play, and Cubicase takes care of the rest: mods, version and connection.
Do you need an account?

No. Cubicase works without signing in. An account is only needed for Cubicase Plus or to link servers to a profile. See Account and sign-in.

Basic

Install and update

From download to first launch, and how the app keeps itself up to date.

Requirements

  • Windows 10 or 11, 64-bit.
  • An internet connection (to download the server and Java, and to connect the mesh network).
  • Enough RAM for the server: the app accepts a minimum of 2 GB for the server, but 3 GB or more is recommended, always leaving at least 2 GB free for Windows.
  • To play, you also need Minecraft Java Edition installed.

Installing

  1. Go to the download page and click Download for Windows.
  2. Open the downloaded .exe installer. There is nothing to configure during installation.
  3. When it finishes, open Cubicase.
Windows SmartScreen warning

Because Cubicase is a new project, Windows may show "Windows protected your PC". That's normal: click More info and then Run anyway. The source code is open on GitHub if you want to check it.

First launch

The first time, the app shows a welcome screen asking what you want to do: Host a server (create and manage your server) or Connect to a server (join a friend's server with a code). This only decides which tab opens first, and you can change it later in Settings → Home.

Updates

Cubicase checks for new versions on its own. When there is one, a "New version available" notice appears with the Update and restart button. The app downloads the update, shows the progress and restarts. If it fails, it tells you and you can try again later. The installed version number appears at the bottom of Settings.

The notice can be dismissed, but the Update button stays in the top bar while a new version exists. If the installation fails, it changes to Try again: the app checks again for an update and tries to install it, with no need to close and reopen the program. After a failure, it stays disabled for a few seconds so it doesn't overload the server, and repeated clicks are ignored.

Updating with the server on

Restarting the app to update interrupts whatever is running. Do it when nobody is playing.

Basic

Getting to know the interface

A quick map of everything you see in the Cubicase window.

Top bar and general shortcuts

  • Host and Guest tabs: switch between managing your own server and using the library of your friends' servers.
  • Settings: general app preferences: startup tab, backups, theme, language, account and subscription. See App settings.
  • Theme switch: quickly toggles between light and dark mode (also in Settings).
  • Update button: only appears when there is a new version. If the automatic update fails, it becomes Try again and you can try once more without closing the app.
  • ? button (Help center): opens shortcuts to this tutorial and the form to report bugs, problems or suggestions. See Help center and contact.
  • Diagnostics center: the history of warnings and errors (network, server, installation…). See Diagnostics.

Host tab

  • Local Servers list (sidebar): all the servers you created or imported. It holds the buttons to create a server, import a server and import a modpack.
  • Selected server panel: name, status (Online, Starting, Stopping, Crash, Offline), invite code, start/stop buttons and RAM/CPU usage.
  • Server Network: mesh network status, the code to share and local settings (folder and port).
  • Console: two tabs, Minecraft Console and Mesh Network, with live logs.
  • Management: players, mods/plugins, world and backups.

Guest tab

The Library of Known Servers: every server you have joined stays saved, with its status, players and the play button.

When you close the window

Cubicase asks what to do: Keep running in the background (server and network keep running) or Close everything (stops the server, the network and the app). See Background and closing the app.

Basic

Create a server

From clicking the "+" to an installed server, step by step.

  1. In the Host tab, in the Local Servers list, click the + button and choose Create New Server.
  2. Fill in the Server Name (e.g. My_Server). See the naming rules below.
  3. Choose the Server Type. If you're unsure, see Which type to choose.
  4. Choose the Minecraft Version. The selector has a search box and groups versions into Recommended, Popular and All Versions.
  5. If the type is Forge, Fabric or Paper, one more selector appears (Forge version, Fabric Loader version or Paper build). The app already selects the recommended/stable option.
  6. Adjust the Allocated RAM (see below).
  7. Optionally, enter a World Seed.
  8. Click Create Server and wait for the installation.

Naming rules

  • It can't be empty or repeat the name of another server of yours.
  • It can't contain the characters \ / : * ? " < > |.
  • It can't end with a space or a period.
  • It can't be a reserved Windows name (such as CON, NUL, COM1).

Minecraft version

Cubicase offers versions starting at 1.8.9. When in doubt, stick to the Recommended ones. If your friends use a specific version (or a modpack requires one), pick exactly that: everyone must play on the same version as the server.

Allocated RAM

This is the memory the server may use. The app shows your PC's total and warns you:

  • Less than 3 GB: can cause slowdowns or freezes, especially with many players or mods.
  • Leaving less than 2 GB for Windows: can make the system slow or unstable, so lower it.

Rule of thumb: a vanilla server with a few friends runs fine on 3-4 GB; heavy modpacks need 6-8 GB or more, if your PC allows. You can change it later in Server Settings.

World seed

Leave it blank for a random world. If you want a specific world, type the seed. You can only set it now: the world is generated the first time the server starts, and the seed can't be changed afterwards. To generate another world later, use Reset World (see World and backups).

What happens during installation

  • The official server files are downloaded (Mojang, Forge, Fabric or Paper depending on the type). This happens once per installed version.
  • The required Java is downloaded automatically when missing (see Automatic Java).
  • Cubicase accepts the Minecraft EULA and creates the initial server.properties for you.
About the EULA

When you create a server through Cubicase, the Minecraft EULA is accepted automatically on your behalf. It's worth reading the terms at minecraft.net/eula.

Basic Intermediate

Which server type to choose

Vanilla, Forge, NeoForge, Fabric or Paper: what each one does and when to use it.

TypeWhat it isExtensionsUse it when…
VanillaThe official Mojang server, unmodified.NoneYou want pure Minecraft, it's your first time, or your group plays without mods.
ForgeThe classic mod loader, with the largest catalog of mods and modpacks.ModsYou'll play a modpack or mods that require Forge.
NeoForgeSuccessor to Forge on newer versions. Cubicase offers it together with Forge, in the Forge version list.ModsThe mod or modpack asks for NeoForge.
FabricA lightweight, fast mod loader, widely used for performance mods.ModsThe mods you want are for Fabric.
PaperA performance-optimized server that supports plugins.PluginsYou want better performance with many people and admin plugins (players join with regular Minecraft, no mods).

Mods versus plugins

  • Mods (Forge, NeoForge, Fabric) change the game from the inside. In general players also need to install the same mods. Cubicase does this for the guest, see Prepare and play.
  • Plugins (Paper) run on the server only, and players join with plain Minecraft.
  • Mods and plugins are not interchangeable. Each loader requires files made for it and for the chosen Minecraft version.
Not sure which to choose?

Start with Vanilla. If you want to add mods later, create another server of the right type (or import the modpack, which sets everything up). The type can't be changed on an existing server.

Basic

Start and stop the server

How to turn the server and the network on, what each status means, and how to shut down safely.

Turning on

  1. Select the server in the Local Servers list. Only one server can run at a time: stop the current one before switching.
  2. Click Start Server. The status goes through Starting until it becomes Online.
  3. For your friends to join, the mesh network must also be active: use Start Mesh Network in the Server Network section. If you start the network with a server selected, Cubicase also starts the Minecraft server automatically as soon as the connection is ready.
  4. When the network is active, Mesh Network Active appears with the code to share.
Server online without the mesh network

If Minecraft is running but the network is off, the app shows a "Mesh network disabled" notice with the Start Mesh Network button. In that state only people on the same local network (LAN) can join.

The first time

The first start can take a while: the app downloads Java (if missing), and Minecraft generates the world. The progress bar shows how it's going and the console shows everything that happens.

The statuses

StatusMeaning
OfflineServer turned off.
StartingJava is up and Minecraft is loading (the app detects "online" by testing the server port).
OnlineReady to receive players.
StoppingThe server is saving the world and shutting down.
CrashThe server closed unexpectedly. See Common errors.

Turning off

  • Click Stop Server and wait until it reaches Offline. Cubicase sends the stop command to Minecraft so everything is saved properly.
  • Stop Mesh Network turns off the network only: the server can keep running locally.
  • From the console you can also use stop.
Avoid killing the process

Forcing Java to close, pulling the PC's plug or ending it in Task Manager can corrupt the world. Always stop it with the button. If it happens, restore a backup.

Automatic Java

You don't need to install Java. Cubicase picks and downloads (from Adoptium) the version your Minecraft version requires and keeps it in the app's data folder:

MinecraftJava used
1.16 and earlierJava 8
1.17 to 1.20.4Java 17
1.20.5 onwardsJava 21

If a server's Java is corrupted or incompatible, Cubicase detects it, reinstalls it automatically and tries to start again, notifying you with "Fixing automatically".

Basic

Invite friends (code and link)

Three ways to hand your server to others: code, link and address.

Server code

Every server has a code in the format CF-XXXX. To copy it, use Copy Server Code (or Copy Code) in the server panel. The guest only needs it once, because afterwards the server stays saved in their library.

Invite link

The Copy invite link button copies an address in the format play.cubicase.net/…. When the link is opened, the guest's Cubicase opens and adds the server to the library. This works through the cubicase://join/… protocol, so the guest needs Cubicase installed.

The free link is based on the code. With Cubicase Plus you can choose a custom address (e.g. play.cubicase.net/my-server) in Server Settings.

Minecraft address

In Server Settings → Minecraft address is the address the player uses in the Multiplayer list. The free address is based on the code and only works while the guest is connected through the app. With Plus you can choose your own name.

Generating a new code

Next to the code there is the Generate new code option. Use it when the code leaked or someone you no longer want there has it.

  • The old code stops working immediately: anyone who only had it can no longer join.
  • You need to give the new code to the people who already play with you.
  • You can only generate a new code with the server stopped.
Want real control over who joins?

The code gives access to anyone who has it. Enable the whitelist so only approved names can play.

Intermediate

Server console

Follow what Minecraft and the network are doing, and send commands.

The two tabs

  • Minecraft Console: all of the server's output (players joining, warnings, errors). It only shows something after you start the server.
  • Mesh Network: private connection logs. Useful for diagnosing when nobody can connect.

The Clear button wipes what's on screen (it doesn't delete the server's log files).

Sending commands

The text box at the bottom of the console only accepts commands when the server is Online. Type without the slash and press Enter. Some useful commands:

CommandWhat it does

whitelist add NameApproves a player (with the whitelist on).
kick NameKicks the player (they can come back).
ban Name / pardon NameBans and unbans.
gamemode creative NameChanges someone's game mode.

weather clearClears the rain.
difficulty hardChanges the difficulty on the spot.
save-allForces the world to be saved.
stopShuts the server down safely.

Many of these commands require your server's version and type to support them. Servers with plugins (Paper) and mods may have extra commands.

Intermediate

Players: whitelist, operators and bans

The Players panel controls who can join and who is in charge of the server, without typing commands.

With the server online, the actions in this panel are sent as commands through the console and take effect immediately. The panel has four tabs:

Online

Shows who is connected right now. With the server off, it says "Server offline — no players connected".

Whitelist (approved list)

While the whitelist is disabled, anyone with the code can join. A notice in the panel reminds you, with the Enable whitelist button.

  1. Click Enable whitelist.
  2. In the Whitelist tab, type the Player name (exactly the Minecraft nickname) and click Add.
  3. To remove someone, use Remove from whitelist and confirm.

You can also turn the whitelist on/off in Server Settings → Whitelist.

Operators

Operators (ops) have administrator permission inside the game: they can use commands such as gamemode and ban. Add with Make Operator; the list shows each one's UUID and level. Remove with Remove operator.

Be careful who becomes an operator

An operator can ban, change game modes and, depending on the level, even shut the server down. Give this power only to people you trust.

Banned

  • Ban: type the name and, if you like, a Reason (optional).
  • Ban IP: blocks an entire IP address.
  • The list has two sections, Banned players and Banned IPs. Use Unban or Remove ban to reverse it.

The Refresh lists button reloads everything in case something changed through a console command.

Intermediate

Mods and plugins

Install, disable and remove mods (Forge, NeoForge, Fabric) or plugins (Paper) without leaving the app.

On servers with a mod loader the panel is called Mods and uses the mods folder. On Paper servers it is called Plugins and uses the plugins folder. Vanilla servers use neither.

Search and install online

  1. Click Browse Mods Online (or Browse Plugins Online). The search uses the Modrinth catalog.
  2. Type the name (e.g. Sodium, WorldEdit). Results only show what is compatible with this server.
  3. Open the item, choose the Version (the app filters by Minecraft version and loader) and click Install.
  4. If the item needs other mods (dependencies), the app warns you under Dependencies not detected, with checkboxes to install them together. If you already installed them manually, just uncheck them.
  5. Restart the server: changes to mods and plugins only apply after that.
If the search doesn't show up

The search needs the app to detect the server's Minecraft version (on imported servers this can fail). If Modrinth is unreachable, you see "No connection to Modrinth" and a button to try again. Mods already installed can still be managed.

Managing what's already installed

  • Disable / Enable: turns a mod off without deleting it (good for testing which mod causes trouble).
  • Delete: removes the file, with confirmation. You can select several (Select all) and use Delete selected mods.
  • Open Mods Folder: opens the folder in Explorer, so you can copy .jar files downloaded from other sites.
  • Refresh list: rereads the folder.

Manual installation

Copy the .jar file into the panel's folder and click Refresh list. Make sure the mod is for the same Minecraft version and the same loader as the server.

Diagnostic tip

Server crashing after you installed something? Disable the most recently added mods one at a time and restart. See also Common errors.

Intermediate

World and backups

Protect your world's progress: manual and automatic backups, restoring and starting over.

Manual backup

  1. Stop the server. The app only manages backups while it is off, so it doesn't copy the world in the middle of a write.
  2. In the World tab, click Back Up Now.
  3. The backup appears in the Backups list.

Automatic backups

Configured in Settings → Backups (see App settings). When enabled, Cubicase creates a backup on its own:

  • when the server is stopped;
  • when the server crashes;
  • periodically in long sessions (interval in hours, configurable).

It skips itself if the world hasn't changed since the last one. You set how many backups to keep (Keep the last N backups): older ones, automatic or manual, are deleted.

Restoring a backup

  1. Stop the server.
  2. In the backup list, click Restore backup on the one you want.
  3. Confirm by typing RESTORE.
Restoring replaces the current world

The world's current progress is lost. If in doubt, back up the current state first.

Resetting the world

Reset World permanently deletes the current world; Minecraft generates a new one the next time the server starts. Confirmation requires typing RESET. Make a backup first if there is any chance you'll want the old world back.

Where backups are kept

They live in a CubicaseBackups folder, separated by server name. If you rename the server, Cubicase moves the backups along; if it can't, it tells you where they stayed so you can move them manually.

Good practice

Backups on the same machine don't protect against a disk failure. From time to time, copy the CubicaseBackups folder to a flash drive or the cloud.

Open it with the Server Settings button in the server panel. Two important rules:

Intermediate

Import an existing server

Already have a Minecraft server in a folder? Bring it into Cubicase without copying or losing anything.

  1. In the Local Servers list, click + and choose Import Existing Server.
  2. Select the folder where the server is (the one that contains the server.jar or equivalent).
  3. Cubicase analyzes the folder and detects the type and version. Then the server appears in the list and the log confirms the import.

What changes for imported servers

  • Files stay in the original folder. Cubicase just starts managing them there.
  • You can't rename the server through Cubicase, since the name comes from the folder.
  • If the Minecraft version isn't detected, the online mod search is unavailable and the version shows as "Not found".
  • A server that is already in the list can't be imported again ("Server already imported").

Removing from the list

When you delete an imported server, Cubicase only removes it from the list. The original files in the folder are not deleted. For servers created by Cubicase, deletion wipes everything (see Delete a server).

Advanced

Import a modpack

Create a modded server from a modpack file, with the loader, version and mods set up automatically.

Cubicase accepts two formats: .zip (CurseForge) and .mrpack (Modrinth).

  1. Download the modpack file from the CurseForge or Modrinth website.
  2. In the Local Servers list, click + and choose Import Modpack (.zip/.mrpack).
  3. Click Click to select the file and choose the modpack.
  4. The app reads the pack and shows a summary: Minecraft version, loader and number of mods.
  5. Enter the Server Name and the Allocated RAM (big modpacks need a lot) and click Import Modpack.
  6. Wait: Cubicase installs the mod loader and downloads all the mods. The bar shows the percentage and large modpacks can take a few minutes.
Mods that need a manual download

Some authors disable third-party distribution. In that case the app lists the mods that couldn't be downloaded automatically. Download them yourself and put them in the server's mods folder after importing (use Open Mods Folder → Refresh list).

Once imported, your friends join as usual. Their Prepare and Play installs the same mods on each person's machine (see Prepare and play).

Basic

Delete a server

How to delete a server and exactly what is lost.

  1. Stop the server. A running server can't be deleted.
  2. In the Local Servers list, use Delete Server on the server you want.
  3. To confirm, type the server name and click Delete Permanently.
There's no undo

For servers created by Cubicase, all worlds, settings and data are deleted. If you want to keep the world, copy the server folder or the backups first. The server is also removed from the central code system, and the code stops working.

For imported servers, only the list entry is removed.

Basic

Join a friend's server

You received a code or a link. Here is how to turn that into gameplay.

Option 1: code

  1. Install Cubicase and open the Guest tab.
  2. Click Add Server (or Add First Server, if the library is empty).
  3. Paste the Invite Code (something like CF-XXXX) and click Add.
  4. The server enters your library. Now go on to Prepare and play.

Option 2: invite link

If the host sent a play.cubicase.net/… link, just open it: Cubicase opens and shows "Server added". If the link is invalid or has expired, the app tells you to check with the host.

The library

You only need the code once: afterwards the server stays saved in Known Servers. Each card shows name, version, status, players (e.g. 3/8) and there are shortcuts for:

  • Copy server code and Copy address;
  • Refresh status, to query again who is online;
  • Remove from library, which only takes it off your list and doesn't affect the server.

If one of the servers is yours, it appears marked Mine.

Basic Intermediate

Prepare and play

The button that installs everything the server requires and opens Minecraft already connected.

Server without mods

Click Play. Cubicase opens Minecraft set up to connect to that server.

Server with mods

Here Prepare and Play appears. When you click it, a Prepare <server> window checks what you already have and shows what it is going to do:

  • Install the loader (Forge, NeoForge or Fabric) in the right version in your Minecraft, if it isn't there yet.
  • Select the right profile in the Minecraft Launcher.
  • Download the missing mods, straight from Modrinth, copy them from the server folder (if the server is on your computer) or download them from the host itself when they don't exist in a public catalog.
  • Isolate everything in a folder of its own for this server, without affecting your regular Minecraft or other servers.

Click Prepare now and follow each mod: ok, Modrinth…, copying…, host… or failed.

When it finishes

  • All good: "Ready to play!". Click Open Minecraft.
  • Some failed: the window lists which ones. Use Try again. If that doesn't fix it, you can Continue anyway, but the server may reject the connection or the game may crash because of the missing mod.
If Minecraft isn't found

Cubicase needs to find the Minecraft Java installation (with the Launcher). If it can't, it tells you and you connect manually. See Manual connection.

Intermediate

Manual connection and tunnel

How the connection works under the hood, and how to connect the "classic" way through the Multiplayer list.

Connect / Disconnect

When you click Connect on the server card, Cubicase establishes a tunnel through the private network to the host. When it finishes, the card shows Connected and the message "Connect to <address> in your Minecraft".

  • The app tries to automatically add the server to your Minecraft Multiplayer list.
  • If it can't find your installation or fails, copy the address with Copy address and add it yourself: in Minecraft, Multiplayer → Add Server, and paste the address.
  • When you're done playing, click Disconnect to end the tunnel.

One tunnel at a time

One Cubicase installation uses the private network either as a host or as a guest at a time. If you're connected as a guest, the host's network button is locked ("In use by Guest mode"), and vice versa. Stop one before using the other.

Local guest port

In System Settings there is the Local Guest Port (default 25565): the local port used only when you join someone else's server. It doesn't affect the servers you host, whose port is set in Server Settings. Only change it if another program is already using 25565.

Wake server

When the host uses the on-demand server, the server stays in Standby until someone needs it. Click Wake server: the app shows "Waking up, please wait…" and turns the server on. If you ask again too quickly, it tells you to wait a few seconds. If the server takes too long, try again.

Without internet

Without a connection to the central system, a notice appears in the library: the information shown is from the last saved snapshot and may be out of date.

Basic

Account and sign-in

An account is optional. It is used for Cubicase Plus and to link servers to a profile.

Signing in

  1. Open Settings → Account and click Sign in.
  2. The browser opens the Cubicase sign-in page. You can sign in with Google, Discord or a magic link (a link sent to your email).

Intermediate Advanced

Diagnostics and automatic alerts

Cubicase watches the server and your PC and warns you before a problem ruins the session.

Diagnostics Center

Every important warning goes into the Diagnostics Center history, classified by source (Network, Server, Panel, Invite, Installation, Backup) and level (Info, Warning, Error, Critical). Use Dismiss to close a warning and Clear history to empty the list.

Lag detection

AlertWhat it means
Server laggingThe server struggled to keep up with the game several times in the last minute. Usually heavy mods, excessive terrain generation or little RAM/CPU.
Severe lagThe server is many milliseconds behind and may freeze soon.
Server freezing (Watchdog)Minecraft itself detected a serious freeze: some mod or plugin may be in a loop. If it repeats, the server may go down.

Resource analysis

When there is lag, the app checks whether the bottleneck is the processor or the memory of the PC, and tells you which:

  • CPU at its limit: lower the View Distance, remove heavy mods or (long term) upgrade the processor.
  • RAM almost full: lower the RAM allocated to the server, close other programs or add RAM to the PC.
  • Neither at the limit: the likely cause is a specific mod/plugin or too many entities/players loaded.

There are also sustained pressure warnings: the computer's CPU or RAM above normal for a few minutes, even before lag shows up. A computer RAM/CPU usage bar (not just the server's) is always visible in the panel.

Out of memory (OutOfMemory)

If the server runs out of RAM, the app compares what you allocated with the PC's total:

  • If the PC has headroom, it suggests a safe value to raise in Server Settings.
  • If the PC is already at its limit, it suggests reducing mods/players, lowering the allocated RAM a bit or upgrading the RAM.
Intermediate Advanced

Common errors and crashes

When the server closes on its own, Cubicase reads the log and explains the most likely cause in plain language.

A red notice appears in the panel with the title and explanation. Click Show technical details for the raw log excerpt (useful when asking for help). If Automatic backup is on, a backup is also made on the crash. Causes the app recognizes:

DiagnosisCause and fix
Two mods with the same IDA mod is duplicated (downloaded twice, or bundled inside another). Delete the extra copy from the mods folder.
A mod or library is missingA mod requires another (a dependency) that isn't installed or is an incompatible version. Install what's missing. The online mod search suggests dependencies.
Mod conflict (mixin)Two mods change the same part of the game. Find the last mod added, disable one of the two and test.
Mod incompatible with the versionA mod was made for another Minecraft or Forge version. Check that all of them match the server's version.
Corrupted worldA region/chunk file is damaged (power loss, forced shutdown). Restore a backup.
Out of memory (OutOfMemoryError)Increase the allocated RAM (if the PC has headroom) or reduce mods/players. See Diagnostics.
Server froze (Watchdog)A mod or plugin stuck in a loop, a query that is too heavy, or a slow disk/network. Check in the details which mod shows up near the error.

A general method to find the culprit

  1. Read Cubicase's notice and the technical details.
  2. Remember what changed: did you install a mod? change a setting? raise the view distance?
  3. Undo the last change (disable the mod, restore the setting).
  4. If the world may be damaged, restore a backup.
  5. If nothing works, ask for help with the log in hand, in Issues on GitHub.
Basic

Nobody can join

A checklist in the order problems show up most often.

On the host's side

  1. Is the server Online? (If it's Starting, wait.)
  2. Is the mesh network active, showing Mesh Network Active? If the "Mesh network disabled" notice is showing, click Start Mesh Network.
  3. Is Cubicase open and the PC not asleep?
  4. Did you not generate a new code recently? If you did, hand out the new code.
  5. Are you currently using the app as a guest of another server? That occupies the network (see Manual connection and tunnel).
  6. Look at the Mesh Network tab of the console for errors.

On the guest's side

  1. Is the code correct? "Server not found" points to a wrong or old code.
  2. Is the status on the card Online? If it's Running without mesh network or Offline, the problem is on the host's side.
  3. Did you use Prepare and Play (or Connect) and wait for "Connected"?
  4. Do your version/mods match the server's? Run Prepare and Play again to reinstall what's missing.
  5. Does the server use a whitelist? Ask the host to add your exact nickname.
  6. Official Minecraft account: with Online Mode on (default), only people with an official account can join.
  7. Try Disconnect and Connect again.
Same version!

Messages such as "incompatible version" in Minecraft mean the player and the server are on different versions. In Guest mode the Prepare and Play button already opens the correct profile.

Help center and contact

Found a bug, have a question or an idea? Talk directly to the people who make Cubicase, without leaving the program.

  1. Click the ? button in the app's top bar.
  2. Choose the Type: Bug, Problem or question, Suggestion or Something else.
  3. Write the Subject (one sentence) and the Description: what happened, what you expected and, if you can, the steps to reproduce.
  4. Enter Your email: that's where the reply goes. It stays saved on this computer for next time.
  5. Leave the option to include the app and system version checked (it helps us fix things faster) and click Send message.
How to write a good report

Say the Minecraft version, the server type (Vanilla, Forge…), whether there are mods, and what appeared in the console or the Diagnostics Center. The more detail, the faster the fix.

The same window has the Quick guides, shortcuts that open the most useful articles of this tutorial in your browser.

About privacy: we use your email only to reply to the message. Nothing beyond what you wrote and the app and system version (if you leave it checked) is sent.

Basic

Frequently asked questions

Is it free?

Yes. Cubicase is free and open source. Cubicase Plus is an optional subscription with extra features.

Do I need to open ports on my router?

No. The connection goes through a private (mesh) network, without exposing your router.

Do my friends need to install Cubicase?

To join with the code/link, yes: their Cubicase makes the connection (and installs the mods, if any). Only the host creates the server.

Does the server work with my PC turned off?

No. The server runs on your computer. If the PC or Cubicase is off, nobody can join. Plus's on-demand mode starts the server when someone arrives, but the computer must be on.

How many players can it handle?

It depends on your RAM, CPU and internet, and on the server type. Start with a few friends and watch the RAM/CPU usage in the panel. If there is lag, see Diagnostics.

Can I have several servers?

Yes, several in the list, but only one runs at a time.

Can I play on Bedrock, on a phone or on a console?

Cubicase is made for Minecraft Java Edition on Windows.

I changed PCs. How do I take my server with me?

Copy the server folder (or the backup) to the new computer and use Import Existing Server.

Where are the server files?

In Server Network → Local settings → Server Directory the path is shown, with the Choose directory button.

How do I change the app language?

In Settings → Language.

I found a bug or have a suggestion

Use the ? button in the app (see Help center and contact). You can also open an issue on the project's GitHub, ideally with the text of the error's technical details.
